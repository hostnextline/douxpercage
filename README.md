# Doux Perçage

Site vitrine une page de **Doux Perçage** — studio de perçage à l'aiguille et
centre de formation, à Montréal. Nour Jeha, fondatrice.

En ligne : <https://hostnextline.github.io/douxpercage/>

## Contenu

Un seul fichier autonome, `index.html` : styles et script inclus, aucune
dépendance de build, aucun framework. Les polices viennent de Google Fonts ;
tout le reste est dans `assets/`.

- `assets/hero.mp4` — boucle de 5 s, sans son, chargée après le premier rendu
- `assets/hero.jpg` — poster, et image affichée si la vidéo ne joue pas
- `assets/og.jpg` — carte de partage, générée depuis `og.html`
- `og.html` — source de la carte de partage (non indexée, non liée)

## Modifier

Ouvrir `index.html` et éditer directement. Le français et l'anglais coexistent
dans le balisage : `<span class="fr">` et `<span class="en">`. Toute chaîne
ajoutée doit exister dans les deux langues.

Aucun suivi, aucun témoin, aucune donnée personnelle collectée.
